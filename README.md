# Estudos de TypeScript

Repositório com exercícios e exemplos práticos desenvolvidos durante meus estudos de TypeScript em cursos.

## Objetivo

Praticar os fundamentos da linguagem, explorando a tipagem e a organização do código por meio de exemplos separados por assunto.

## Conteúdos estudados

- Configuração do TypeScript e do arquivo tsconfig.json
- Compilação de TypeScript para JavaScript
- Tipagem explícita e inferência de tipos
- Tipagem de funções e objetos
- Tipo any
- Propriedades e valores opcionais
- Arrays e tuplas
- Enums
- Interfaces
- Generics
- Type aliases
- Type assertions
- Union types
- Verificação de tipos
- Organização e utilização de módulos

## Tecnologias

- TypeScript
- JavaScript
- Node.js e npm

## Organização

Os exercícios estão organizados em pastas por assunto, com exemplos em arquivos TypeScript. Algumas pastas também contêm arquivos JavaScript gerados pela compilação.

## Como utilizar

1. Clone este repositório.
2. Abra a pasta no seu editor.
3. Instale as dependências:

   npm install

4. Acesse a pasta do assunto que deseja estudar e consulte os exemplos.

A configuração e a execução podem variar entre as pastas, pois os exercícios exploram diferentes recursos da linguagem.

## Observação

Este repositório tem finalidade educacional. Os exemplos foram desenvolvidos acompanhando cursos e atividades de estudo e não representam uma aplicação de produção.
